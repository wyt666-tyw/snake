# 贪吃蛇 Snake

一个基于 HTML5 Canvas 的经典贪吃蛇网页小游戏。

## 快速开始

无需安装任何依赖，直接用浏览器打开 `index.html` 即可：

```bash
# 方式一：直接双击 index.html
# 方式二：命令行打开（Windows）
start index.html
```

## 操作方式

- 方向键 ↑ ↓ ← → 或 W A S D：控制蛇的移动方向（手动模式）
- 开始 / 暂停：使用页面上的按钮（或回车开始、空格暂停）
- 点击「AI 自动模式：关 / 开」按钮可随时切换 **手动模式 / AI 自动模式**，模式选择跨局保留

## 游戏规则

- 吃到红色食物：蛇身变长一节，得分 +10
- 撞到墙壁或自己的身体：游戏结束
- 最高分通过浏览器 localStorage 本地保存，刷新页面不丢失

## AI 自动模式

AI 每一步按以下优先级决策，在**保证生存**的前提下吃食物：

1. BFS 搜索蛇头到食物的最短路径，并模拟整条路径，确认吃完后仍有足够活动空间才前往
2. 追食物不安全时，沿路径跟随自己的蛇尾绕圈，避免把自己封死
3. 仍无路时走向可达空间最大的邻格
4. 彻底无路可走才会死亡（不保证永不死亡，但死亡概率显著降低）

二. AI错误信息记录
- 错误现象：AI生成的贪吃蛇AI寻路代码出现错误，蛇经常原地来回打转，明明食物很近，却反复移动撞到自己死亡，不能连续吃到多个食物。
- 查证过程：
1. 在控制台打印蛇头候选方向和食物坐标，观察移动逻辑；
2. 发现AI只计算到食物的距离，没有判断下一步位置会不会撞到自身蛇身；
3. 查阅贪吃蛇寻路资料对比代码，确认缺少安全格子过滤逻辑，只判断距离而不判断格子是否危险。
- 修复方案：增加安全方向过滤，直接剔除撞墙、会撞到自己身体的方向，只在安全方向中挑选离食物最近的方向，解决自杀打转问题。

四. AI生成代码关键逻辑解释
1.蛇身移动原理
蛇身由一组坐标数组存储，数组首项是蛇头。每次移动，先算出蛇头新坐标；没有吃到食物就删除数组最后一位蛇尾，吃到食物则保留蛇尾，再把新蛇头坐标放到数组最前面，完成移动，实现吃到食物身体变长。
2.AI寻路判断逻辑
AI优先朝着食物方向前进，并且提前预判下一步坐标，过滤掉超出边界和落在蛇自身上的危险位置。在所有安全方向里，挑选距离食物最近的方向，以此在尽量规避死亡的情况下，持续寻找食物。
