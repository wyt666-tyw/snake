# 贪吃蛇 Snake

一个基于 HTML5 Canvas 的经典贪吃蛇网页小游戏。

## 快速开始

无需安装任何依赖，直接用浏览器打开 `index.html` 即可：

```bash
# 方式一：直接双击 index.html
# 方式二：命令行打开（Windows）
start index.html
```

## 操作方式

- 方向键 ↑ ↓ ← → 或 W A S D：控制蛇的移动方向
- 开始 / 暂停：使用页面上的按钮
